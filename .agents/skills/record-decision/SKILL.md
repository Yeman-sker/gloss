# 记录决策

1. 在 `docs/decisions/` 找到下一个编号，创建 `NNNN-短标题.md`。
2. 写日期、状态、背景、决定、理由、代价。有实验数据就链接到 `docs/research/`。
3. 在 `docs/decisions/README.md` 增加一行。
4. 如果取代了旧决定，只在旧记录顶部标注"已被 NNNN 取代"，并更新索引状态，不改旧结论。
5. 同步受影响的 `AGENTS.md`、`ARCHITECTURE.md`、`CORE.md`。
