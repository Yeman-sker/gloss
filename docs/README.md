# 文档索引

文档就是项目的记忆。每份文档只负责一件事，避免同一事实写在多处。

| 文档 | 回答什么问题 | 何时更新 |
|---|---|---|
| [STATUS.md](STATUS.md) | 现在做到哪了？下一步？ | 进度一变就更新 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 系统如何分层？ | 分层变化时 |
| [CORE.md](CORE.md) | core 是什么，契约是什么？ | 契约变化时 |
| [EXTENDING.md](EXTENDING.md) | 怎么加功能？ | 扩展方式变化时 |
| [DEVELOPMENT.md](DEVELOPMENT.md) | 怎么构建、协作、写文档？ | 流程变化时 |
| [decisions/](decisions/) | 当初为什么这样选？ | 做重要决定时新增，不改旧结论 |
| [research/](research/) | 实验测出了什么？ | 做实验时新增，保留原始数据 |
| [journal/](journal/) | 每次工作发生了什么？ | 每次收尾时追加 |

## 记什么

- **写：** 代码看不出来的东西，如原因、取舍、实测数据、踩过的坑和当前进度。
- **不写：** 能从代码或 git 历史直接读到的内容。
- **标明确定性：** 结论要写明已实测（含平台和日期）、推测或未测。
