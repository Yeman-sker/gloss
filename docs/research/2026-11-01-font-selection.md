# 打包字体选型

**日期：** 2026-11-01 **平台：** macOS 实测，Windows 未测
**结论：** 可行。选定的组合让程序增加约 2.8MB，决定见 [0006](../decisions/0006-bundled-fonts.md)。

## 已实测（macOS，mygo v0.7.4）

用临时程序调用 `ui.RegisterFont`，再用 `CapturePage` 截图看真实渲染。程序未进入仓库。

- `Font("Geist, 中文字体")` 的逗号列表可用：西文用前者，中文用后者。
- 可变字体 Geist 的 `FontWeight` 生效。
- 注册耗时：第一个字体约 9ms，之后每个不到 1ms。首次绘制中文的耗时和内存占用未测。
- 字重比较：思源黑体 400 在深色底上偏重，300 又比 Geist 400 细，350 与 Geist 400 最协调。
- 弯引号：字体列表把 Geist 放在最前时，中文里的“”用西文字形，显得局促。把只含四个弯引号的思源黑体子集放到列表最前可以解决，但只能用于含中文的文本，否则英文引号会变成全角。

## 体积

中文裁切范围：GB2312 加 ASCII、拉丁补充和常用标点，共约 7800 个字符。

| 文件 | 原始 | gzip |
|---|---|---|
| 思源黑体 350 裁切版 | 2.45MB | 1.51MB |
| Geist（可变，完整） | 0.17MB | 0.09MB |
| Geist Mono（可变，完整） | 0.17MB | 0.09MB |
| 音标子集（来自 Inter） | 5KB | 3KB |
| 弯引号子集（来自思源黑体） | 3KB | 未测 |

对比：思源黑体可变完整版 17MB，裁切后的可变版 4.12MB。当时主程序约 11.2MB。

## 覆盖缺口

- Geist 和 Geist Mono 缺 `ɡ ɒ ˌ ɑ ː ʃ ɪ ʊ ʌ ɔ θ ʒ ɛ ɜ`，所以音标单独用 Inter 的子集。
- 生僻字、日文假名和韩文不在裁切范围内，会回退到系统字体。

## 授权

字体文件内的授权信息都是 SIL OFL 1.1。思源黑体声明了保留字体名 `Source`，修改版的字体名不能使用它。发布时要附带授权文本。

## 未测

- Windows 上的注册、字体列表、渲染粗细和小数缩放。
- 把字体接入真实面板后的启动时间和内存。
- 中英文之间的间距：mygo 不会自动加，目前依赖译文自带的空格。
