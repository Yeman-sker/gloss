# 0006 打包字体，不用系统字体

**日期：** 2026-11-01 **状态：** 已接受，已接入 `app/`

**背景：** 系统字体在 macOS 和 Windows 上字形不同，产品观感割裂。负责人认为字体和字号是当前不够精致的主要原因。

**决定：**

| 角色 | 字体 | 字号/行高 | 颜色 |
|---|---|---|---|
| 译文 | Geist + 思源黑体 | 15/24 | `#E6E6E8` |
| 单词释义 | Geist + 思源黑体 | 20/28 | `#E6E6E8` |
| 原文 | Geist Mono + 思源黑体 | 12/20 | `#ACACAD` |
| 音标 | Inter 的音标子集 | 12/20 | `#ACACAD` |

- 思源黑体只打包一档 350 字重，裁切到约 7800 个字符。层次靠字号和颜色，不用粗体。
- 译文不再按长度改变字号。
- 含中文的文本把弯引号子集放在字体列表最前，纯英文文本不放。

**理由：** 同一份字体让两个平台字形一致。思源黑体在小字号下规整，Geist Mono 让原文有辨识度，Geist 让英文译文更易读。霞鹜文楷好看但偏文艺，负责人认为不够专业。实测数据见[字体选型](../research/2026-11-01-font-selection.md)。

**待复查：** 350 只在 2 倍屏上看过，要在 1 倍屏和 Windows 125% 缩放下确认。如果发虚，改回 400。

**代价：**

- 程序增加约 2.8MB（实测文件大小之和），对比当时约 11.2MB 的主程序增加约 25%。这是对“守住轻量”的一次明确让步。
- 生僻字、日文假名和韩文会回退到系统字体。
- 两个平台的渲染引擎不同，笔画粗细仍可能有差别。Windows 未实测。
- 发布时要附带字体授权文本；思源黑体的修改版不能以 `Source` 命名。

**更新（2026-11-06，GLO-38）：** 加了粗体。原来只有 350 一档，Markdown 的强调在中文里看不出来。现在多打包两个 600 字重的子集：思源黑体粗体只保留 GB2312 一级汉字和常用标点（`cjk-bold.ttf`，1.2 MB），Geist 粗体（`geist-bold.ttf`，79 KB）。两者和常规体用同一个字族名注册，mygo 按字重自动选择；二级汉字的粗体由渲染器加粗常规体代替。程序因此增加约 1.3 MB。正文层次仍然靠字号和颜色，粗体只用于强调和标题。macOS 2 倍屏已截图核对，1 倍屏未看。
