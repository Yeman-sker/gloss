# 0010 设置声明增加 Label

**日期：** 2026-11-06 **状态：** 已接受，已接入 `core/`（GLO-26）

**背景：** 设置界面要为每个功能自动生成设置页。0007 的设置声明只有键和说明（`help`），界面只能拿 `target_lang`、`depth` 这样的键当标题，或者把一句说明塞进标题位置。

**决定：** `core.Setting` 增加可选字段 `Label`，是设置项在界面上的名字（如“目标语言”）；`Help` 继续作为标题下方的一句说明。没有 `Label` 时宿主退回显示 `Key`。提示词功能的 `spec.json` 对应增加 `label`，四个内置功能都已填写。

**理由：** 向后兼容的新增，旧声明和测试不用改；界面上的名字由功能自己给，宿主不去猜。

**代价：** 插件声明多一个字段要写；不写时界面会露出英文键名。
