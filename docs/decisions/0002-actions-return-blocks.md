# 0002 Action 只返回结构化 Blocks

**日期：** 2026-11-01 **状态：** 已接受

**背景：** 产品不只翻译，以后要靠插件扩展，同时要保持极其精致的动效。如果插件能带自己的 UI，体验就无法保证。

**决定：** core 的抽象是"文本和上下文 → 流式 Blocks"，不是 `translate(text, from, to)`。Action 只表达语义，界面由 `app/` 统一渲染。

**理由：** 所有功能自动继承动效和品牌风格，更换视觉不影响功能，并且 core 可以脱离窗口测试。

**代价：** 插件无法自定义界面。新的展示形式要先在宿主中增加 BlockKind。这个限制是有意的。
