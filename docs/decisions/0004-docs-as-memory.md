# 0004 文档即记忆

**日期：** 2026-11-01 **状态：** 已接受

**背景：** 两位开发者和多个 Agent 协作。Agent 的新会话没有历史，对话内容也不共享。

**决定：** 项目状态、决定和实验数据都写进仓库。`AGENTS.md` 是所有 Agent 的统一入口，`CLAUDE.md` 只引用它；`docs/STATUS.md` 是唯一的进度来源；共享工作流放在 `.agents/skills/`。

**理由：** 新会话或另一位开发者能立刻知道进度，避免多个工具各维护一份规则。

**代价：** 每次收尾要花一点时间更新文档，所以把它写进了完成的定义。
