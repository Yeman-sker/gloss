# 0003 取词放在独立的 Rust 进程

**日期：** 2026-11-01 **状态：** 已接受

**背景：** mygo 没有提供读取其他应用选区的能力，需要调用系统接口。负责人希望使用 Rust。

**决定：** 用独立的 Rust helper，通过 stdin/stdout 按行传 JSON。

**理由：**
- 不把 Rust 链接进 Go，保留 mygo 的纯 Go、无 cgo。
- helper 崩溃不会带垮主程序。Windows 验证中确实出现过 helper 崩溃。
- 平台代码集中，体积很小（约 331KB）。

**代价：**
- 多一套工具链，发布时要为每个平台分别构建 helper，打包流程尚未实现。
- mygo 依赖 `purego`，Go 其实也可能直接调用系统接口。如果 Rust 成为负担，可以替换；helper 的协议使替换不影响其他部分。
