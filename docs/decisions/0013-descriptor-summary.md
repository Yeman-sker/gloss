# 0013 功能描述增加面向用户的 Summary

**日期：** 2026-11-06 **状态：** 已接受，已接入 `core/`（GLO-45）

**背景：** 设置界面直接显示 `Descriptor.Purpose`。`Purpose` 是写给路由模型看的（“用户读不懂或想确认一段外文的意思”），用户读起来像提示词。改写它会影响路由判断。

**决定：** `core.Descriptor` 增加可选字段 `Summary`，是写给用户看的一句说明；`spec.json` 对应增加 `summary`，四个内置功能都已填写。宿主显示 `Summary`，没有时退回 `Purpose`。`Purpose` 不变，路由继续用它。

**理由：** 向后兼容的新增。两个读者要的话不一样，不应该共用一句。

**代价：** 功能作者多写一句话；不写时界面会露出给模型看的文字。
