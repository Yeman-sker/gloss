# 0011 设置界面的视觉语言：墨与荧光

**日期：** 2026-11-06 **状态：** 已接受方向，颜色、圆角和手感待负责人上手确认（GLO-41）

**背景：** 0.1.0 的设置界面是 mygo 默认控件加蓝色强调色，和贴纸图标、墨色面板都不是一个产品。方向样张里比较了 A 墨与荧光、B 贴纸册、C 墨色精工（负责人选 A，并提出三点：图标太艳、要设计好圆角、要做好交互）。

**决定：**

- **隐喻：** 划词就是 Gloss 的动作，所以“选中”长成荧光笔划过的样子：导航选中时笔触紧贴文字划过，保存成功时在该项名称上划一道，开关的开启色和焦点环用同一支笔的颜色。
- **颜色：** 底是墨（窗口 `#111114`，内容面板 `#17171B`），荧光黄 `#FFD43B` 配墨字表示选中和开启，番茄 `#FF5B3A` 只用于主要按钮和待办提示，奶白键帽来自贴纸。
- **圆角：** 不靠感觉定。半径约为高度的 28%；嵌套时同心，外 = 内 + 间距。具体数值在 `app/tokens.go`：标签 5、小按钮 7、菜单项 8、输入框和按钮 9、弹出层 12、内容面板和卡片 14、确认框 16、面板 18。
- **反馈：** 按下下沉（弹簧回弹），悬停颜色过渡 130 ms，图标悬停和选中时形变并亮一档。自动保存没有保存按钮，靠笔触证明已经写入。减弱动效时没有位移，笔触直接到位。
- **布局：** 每页是一列，宽 520，在内容面板里居中；窗口太窄时左右至少留 32，列随之变窄（`pagePadding`）。行之间靠留白分开，不用细线，不到处堆卡片，只有服务这类独立对象才用卡片。
- **信息密度（负责人 2026-11-06 要求）：** 默认只露出多数人会改的设置，其余收进每页底部的“高级”。说明文字只在名称和取值说不清时才写，能放进占位符或选项的就不单写一行。导航只有通用、模型服务、功能、自动选择四项；各功能从功能列表点进去，不再占导航，这样功能变多（插件）时导航也不会变长。
- **字号：** 只有四档：标题 24、正文 14、说明 13、小字 12（`app/prefs_ui.go`）。层次靠字号、颜色和留白，不靠线和框。

**理由：** 隐喻改变了行为，不只是换皮。颜色来自已定的贴纸图标，品牌只有一套来源。

**代价：** mygo 的 `Sidebar`、开关、下拉和输入框的外观都要自己画（`app/prefs_ui.go`），约 800 行。面板的蓝色强调色也要跟着换（GLO-48），否则两边仍不是一个产品。手绘笔触是路径，每个选中项每帧重建，只在动画期间发生。
