# 0005 文档记录事实，Linear 管理规划

**日期：** 2026-11-01 **状态：** 已接受

**背景：** 两位开发者和多个 Agent 协作，既要留下可靠的记忆，也需要一个能持续调整计划的地方。

**决定：** `docs/` 记录现状、决定、原因和实测数据。[Linear 的 GLO 团队](https://linear.app/yeman/team/GLO/overview) 用来在讨论计划后逐步打磨 issue 和开发安排。Issue 来自讨论，Agent 经用户同意才能创建或调整。

**理由：** 事实和规划的变化方式不同。事实需要长期可靠，规划需要随理解不断调整，分开后互不干扰。

**代价：** 依赖外部服务，Agent 需要配置 Linear 访问权限。长期有效的结论必须写回仓库，不能只留在 issue 里。
