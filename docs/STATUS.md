## 已知问题

这里记录已确认的事实。要不要修、何时修，讨论后在 Linear 规划。

| 问题 | 影响 | 状态 |
|---|---|---|
| Cmd+C 兜底只恢复纯文本剪贴板 | 可能丢失图片等内容 | 必须在发布前修复 |
| macOS 查询前台应用要启动 `lsappinfo`，约 20ms | 取词变慢 | 待改用 NSWorkspace |
| 原型曾有一次 AX 和 Cmd+C 都失败，原因未确认 | 取词可靠性 | 观察中 |
| 与 Bob 共用 `Alt+Shift+D`，Gloss 不报冲突（macOS，用户实测） | Bob 运行时用户看到的是 Bob 的结果 | 待讨论 |
| 程序增至约 13.9MB，内存常驻 44–46MB，绘制后短暂峰值约 100MB（macOS 实测，此前 31–33MB） | 偏离“守住轻量”，峰值来源未查明 | 待讨论 |
| 面板交互仍有抖动、不够丝滑（macOS 160Hz，负责人实测）；录屏里点击时有 57–82ms 的帧间隔，原因未查明 | 手感未达预期 | 待修 |
| 在 Claude 桌面端选中多段文字时，有时提示“先选中一段文字”（负责人录屏） | 取词失败 | 待查 |
| mygo 只在应用激活时跟踪鼠标，而 Gloss 从不激活。macOS 上面板用私有 API `SetsCursorInBackground` 自己设置鼠标样式 | 系统升级后可能失效，失效时只是样式不变 | 观察中 |
| 面板未实测：关闭动画、点外部关闭后的拖选变淡、单词大字号、音标块、重试按钮、甩动惯性、已打开时滑到新位置、长文滚动和隐藏的滚动条、减弱动效、1 倍屏 | 可能有问题 | 待验证 |
